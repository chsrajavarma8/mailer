      Mailer

      A private, self-hosted bulk email tool. It sends a personalised email to every person on a list, using your own Gmail or Outlook account, from a dashboard that runs only on your computer.

      • Personalised: any column in your list (name, branch, slot…) can be dropped into the subject or message.
      • Safe to re-run: everyone who received the email is recorded, so an interrupted send just picks up where it stopped. Each run is kept as a campaign you can resume.
      • Resilient: temporary server errors are retried with a growing pause; bad addresses aren't; the daily sending limit is respected.
      • Private: no cloud service, no account, no installs. Your list and password never leave your machine except to your own mail server.
      Getting started
      1. Install Python 3.9 or newer. Get it from python.org and tick “Add Python to PATH”. Nothing else to install.
      2. Start the dashboard. Open a terminal in the project folder and run:
        python app.py
        Your browser opens http://127.0.0.1:8765. Keep the terminal open while you work; Ctrl+C stops it.
      3. Create a Gmail App Password. Turn on 2-Step Verification, then create one at myaccount.google.com/apppasswords.
      4. Settings → Mail account. Enter your name, address, login and the app password. Click Test connection.
      5. Settings → Security. Set a dashboard password and click Encrypt now for the app password (recommended).
      6. Recipients. Import a CSV (comma, semicolon or tab separated; the email column is found automatically, e.g. Email, E-mail, Email Address) or type rows in. Click Remove duplicates.
      7. Compose. Write the subject and message, insert {{name}}-style fields, optionally add an HTML version, and step through the preview. Click Send test to me.
      8. Send. Fix anything listed under Problems, then click Send and watch the progress.

      Placeholders & attachments

      Write {{column}} anywhere in the subject or message (the older {column} form works too). With a list like this:

      email,name,slot
asha@example.com,Asha,10:00 AM

      Hi {{name}}, your slot is {{slot}}. becomes Hi Asha, your slot is 10:00 AM. Names are matched ignoring upper/lower case, and columns with spaces work too: {{First Name}}. Unknown fields are highlighted in the preview and left as-is.

      HTML version: open HTML version under the message to add a formatted email. Values from the list are HTML-escaped automatically. Mail apps that can't show HTML fall back to the plain-text message. The preview runs in a sandbox, so scripts don't run and remote images aren't loaded there.

      Saved templates: use Save as… in the Template card to keep a message for later, and Load to bring it back.

      To attach files, upload them on the Recipients tab and choose them in each person's attachment column. Several files: brochure.pdf;map.png. Only files inside attachments/ can be sent.

      Resending

      Normally anyone already marked Sent is skipped so nobody gets a duplicate. To send again on purpose:

      • One person: click ↻ on their row in Recipients.
      • Several or all: on the Send tab, tick people under Resend to members already sent (or tick the header box for everyone), then click Resend.

      Resends are recorded in the history with the note resend. Failed sends are never marked as sent, so a normal Send retries them.

      Resuming a campaign: every send run is saved under Send → Campaigns with a copy of its list and message. If a run was stopped, hit the daily limit, or the computer shut down mid-send, click Resume: it continues with that saved copy and skips everyone already sent, without touching your current list or message.

      Reset & backups

      Settings → Reset dashboard clears the recipient list, subject and message, send history and attachments (pick any of them) so you can start a new campaign. Your mail account, app password and security settings are kept.

      A backup is saved to backups/ first. Restore any backup from the Backups card; the current state is backed up again before restoring, so a restore can be undone too. Clearing history also makes a backup.

      Security
      ProtectionHow
      Network exposureListens on 127.0.0.1 only; requests with any other Host header are refused (blocks DNS-rebinding).
      Dashboard lockOptional password, hashed with PBKDF2-SHA256 (600,000 rounds, random salt). Never stored in plain text.
      Brute forceAfter 5 wrong passwords, logins pause for 30 s, doubling each time (up to 15 min).
      SessionsRandom 256-bit session ID in an HttpOnly, SameSite=Strict cookie; expires after the idle timeout; changing the password signs out other sessions.
      Cross-site attacksPer-session CSRF token on every change; JSON-only requests force a CORS preflight that is never approved.
      Script injectionContent-Security-Policy with a per-page nonce, all output escaped, X-Frame-Options: DENY, nosniff, no referrer.
      App passwordEncrypted at rest with Windows DPAPI (only your Windows account can read it); never sent to the browser.
      Mail transportSTARTTLS (587) or SSL (465) with full certificate verification.
      FilesAttachments confined to attachments/; executables/scripts blocked; 25 MB upload cap; header-injection safe.
      AccountabilityLogins, settings changes, sends, resets and restores are recorded in audit_log.csv (never passwords).

python send_mails.py --check             # health check
python send_mails.py --send              # send to everyone not yet sent (asks to confirm)

      Troubleshooting
      “Login failed” / “Username and Password not accepted”

      Gmail needs a 16-character App Password, not your normal password. 2-Step Verification must be on. Paste it in Settings and click Test connection.

      Many “Connection unexpectedly closed” or “please run connect() first” errors

      The server dropped the connection. Mailer reconnects automatically and retries with a growing pause (Settings → Retries). If it keeps happening you have probably hit the daily limit (about 500 a day for personal Gmail, 2,000 for Google Workspace); Mailer stops the campaign when the server reports that. Wait 24 hours, then click Resume on the campaign. Sent people are skipped.

      “Daily limit reached”

      Mailer counts sends in the last 24 hours against Settings → Daily limit and stops before going over. Set it to your account's real limit (500 for Gmail, 2,000 for Google Workspace), or 0 to turn the check off.

      My CSV uses semicolons or a column called “E-mail”

      Both are detected automatically on import. If the email column can't be found, rename it to email, or on the command line use --email-column "Your Column".

      Emails go to spam

      Increase the delay between emails, keep links few, avoid all-caps subjects, send yourself a test first, and send from an address recipients recognise.

      “attachment not found” or “must be in the attachments folder”

      Upload the file on the Recipients tab and use the name shown there (for example attachments/brochure.pdf).

      I forgot the dashboard password

      Stop the server, open config.ini, clear the value after dashboard_password =, then start again. Your mail settings are not affected.

      “The saved password could not be decrypted”

      The app password was encrypted by a different Windows user or computer. Enter it again in Settings.

      Port 8765 is already in use

      Mailer is probably already running in another terminal. Or start it on another port: python app.py --port 9000.
